# Strategy course: synthesis project

Updated: 7 November 2026.

## Purpose

Example client project of the library: an imagined course on strategy, built only from the AOW notes. It
shows how layer 3 works with a single source: the sheets cross the voices of one book (Sun Tzu, the
classical commentators, the translator Giles) and keep their divergences side by side.
